# Customer Churn Prediction

## Project Overview
This project predicts whether a customer will churn using machine learning.

## Objective
Build a classification model to predict customer churn based on customer demographics, subscription details, and service usage.

## Dataset
- Customer Churn Dataset
- Training data:
  - customer_churn_dataset-training-master.csv
- Testing data:
  - customer_churn_dataset-testing-master.csv

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Model
- Random Forest Classifier

## Project Workflow
1. Data Loading
2. Data Exploration
3. Data Preprocessing
4. Label Encoding
5. Train-Test Split
6. Model Training
7. Model Evaluation
8. Confusion Matrix Visualization

## Results
The Random Forest classifier achieved excellent prediction performance on the provided dataset.
