# 📊 Customer Churn Prediction

## 📖 Project Overview

This project predicts whether a customer is likely to churn using a Machine Learning classification model. It demonstrates the complete machine learning workflow, including data preprocessing, exploratory data analysis (EDA), feature engineering, model training, evaluation, and visualization.

---

## 🎯 Objective

Develop a classification model to predict customer churn based on customer demographics, subscription details, and service usage. The goal is to help businesses identify customers who are likely to leave and take proactive retention measures.

---
