An AI-powered Study Assistant built using **Python**, **Streamlit**, and **Google Gemini AI**.

The application helps students understand concepts, summarize notes, generate quizzes, create revision notes, and answer academic questions through a clean and interactive web interface.

---

## 🚀 Features

- 📖 Explain difficult concepts in simple language
- 📝 Summarize long notes into key points
- ❓ Generate quizzes automatically
- 💡 Answer study-related questions
- 📚 Create concise revision notes
- ⚡ Powered by Google Gemini AI
- 🎨 Modern Streamlit UI
- 🔒 Secure API key using `.env`

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/2021Anandan/Epochs-Bootcamp-2026.git
```

Go to the project folder

```bash
cd Epochs-Bootcamp-2026/Day10
```

Create a virtual environment

```bash
python -m venv .venv
```

Activate it

### Windows

```bash
.venv\Scripts\activate
```

### Linux / macOS

```bash
source .venv/bin/activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

## 🔑 Configure Gemini API

Create a file named

```
.env
```

Add your API key

```env
GOOGLE_API_KEY=YOUR_API_KEY
```

---

## ▶️ Run the Application

```bash
streamlit run app.py
```

The application will open in your browser.
