# Northwind SQL Sales Analysis

## Database Overview

The Northwind database is a sample business database representing a trading company. It contains customers, products, suppliers, employees, orders, and shipping information. This project uses SQL queries and Python (Pandas) to analyze sales performance and generate business insights.

## Project Overview

This project analyzes the Northwind sample database using SQL and Python. It demonstrates SQL querying, data analysis with Pandas, and data visualization using Matplotlib.

## Technologies Used

- SQL (SQLite)
- Python
- Pandas
- Matplotlib
- Jupyter Notebook
- Git & GitHub

## Project Structure

```text
Northwind-SQL-Analysis/
│
├── database/
│   └── northwind.db
├── notebooks/
│   ├── analysis.ipynb
│   └── analysis.html
├── queries/
│   └── queries.sql
└── README.md
```

## Analysis Performed

- Top 10 Products
- Top Customers by Revenue
- Monthly Sales Trend
- Sales by Category
- Revenue by Country
- Product Category Revenue
- Interactive Charts using Matplotlib

## Output

- SQL Queries
- Jupyter Notebook
- HTML Report
- GitHub Repository
