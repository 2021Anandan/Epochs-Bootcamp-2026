# 🎵 Spotify Tracks Data Visualization

## 📌 Overview

This project was completed as **Day 04** of the **Epochs Data Science Bootcamp 2026**.

The objective is to perform Exploratory Data Analysis (EDA) and create meaningful visualizations using the Spotify Tracks dataset to discover patterns, trends, and relationships between musical features.

---

## 📂 Dataset

- Dataset: Spotify Tracks Dataset
- Format: CSV
- Records: Spotify songs and audio features
- Domain: Music Analytics

---

## 📋 Features

The dataset includes attributes such as:

- Track Name
- Artist
- Album
- Popularity
- Danceability
- Energy
- Loudness
- Speechiness
- Acousticness
- Instrumentalness
- Liveness
- Valence
- Tempo

---

## 🛠 Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📊 Workflow

1. Load Dataset

## 📈 Visualizations

The notebook includes visualizations such as:

- Distribution plots
- Histograms
- Count plots
- Scatter plots
- Box plots
- Correlation Heatmap

## 🔍 Key Observations

- Popularity varies significantly across songs.
- Audio features exhibit different statistical distributions.
- Some variables are strongly correlated.
- Visualization helps identify trends and outliers.
- Musical characteristics differ across tracks.
