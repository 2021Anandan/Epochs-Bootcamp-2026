# Netflix Dataset Analysis

## Overview
This project is part of the muLearn Data Science Bootcamp Day 1 assignment.

## Dataset
Netflix Movies and TV Shows Dataset

## Business Problem
Netflix has a vast collection of movies and TV shows. Users often spend significant time searching for content to watch. This project explores the dataset to understand its characteristics and support content recommendation.

## Machine Learning Problem
Content Recommendation System

## Exploratory Data Analysis
- Loaded the dataset using Pandas
- Explored dataset shape
- Checked data types
- Identified missing values
- Generated summary statistics
- Documented key observations

## Key Observations
1. The dataset contains 8,807 titles and 12 columns.
2. Movies are more common than TV Shows.
3. The director column contains the highest number of missing values.
